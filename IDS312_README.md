## Overview

End-to-end project management plan for a simulated CRM implementation at HelpingHands Community Services, Inc. — a nonprofit with 12 regional offices replacing a 15-year-old legacy database with a cloud-based CRM platform.

This project mirrors a real enterprise software rollout: requirements gathering, vendor selection, data migration, user acceptance testing, staff training, and change management — all within a $150K budget and 9-month timeline.

---

## Business Problem

HelpingHands managed volunteer programs, donor engagement, and fundraising across 12 offices using an outdated legacy system with limited reporting, frequent data errors, and no centralized data view. Staff frustration and donor retention concerns made modernization urgent.

**Solution:** Implement a cloud-based CRM to unify volunteer, donor, and event data across all offices.

---

## Project Scope

- Requirements gathering across 12 regional offices  
- Vendor evaluation and selection support  
- CRM configuration planning  
- Data migration planning and execution (targeting 95% accuracy, \<5% data loss)  
- User acceptance testing (UAT)  
- Training delivery targeting 80% staff proficiency within 30 days of go-live  
- Governance framework: data standards, user roles, reporting expectations

**Out of scope:** Custom software development, long-term help desk staffing, fundraising strategy redesign.
